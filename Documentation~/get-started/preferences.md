# Preferences

Understand the settings the Composition Layers package adds to the Unity Preferences window.

## Preferences reference

The XR Composition Layers package adds the following settings to the Unity **Preferences**:

| Setting | Description |
| :------ | :---------- |
| **Display Angles As** | Choose whether the various angle values that you can set in the Composition Layer components use **degrees** or **radians**. |
| **Emulation in Scene** | Display composition layers in the Scene view. |
| **Emulation In Play Mode** | Display composition layers in the Game view while in Play mode when no XR provider is active or no headset connected. |

> [!TIP]
> Emulation of composition layers can sometimes interfere with normal scene editing and troubleshooting. You can use the emulation preferences to disable emulation in such cases.
